# 新功能使用说明：订阅自动更新 与 AI 发现

这两块是这个版本相对原始系统新增的能力。两者都从侧栏底部的 **「更新与发现」** 进入，也可以点顶栏的「新节目」。

界面分三个页签：**新节目** / **AI 发现** / **设置**。

---

## 一、订阅自动更新

原来的系统只有手动点「更新目录」。现在它会自己问。

### 打开自动检查

1. 侧栏「更新与发现」→「新节目」；
2. 勾上「定时自动检查」；
3. 填间隔（5 – 1440 分钟，默认 30），点「保存设置」。

设置立刻生效，不用重启服务。想马上验证效果就点「立即检查全部」。

### 它会做什么

- 到点后**逐个**同步所有订阅源的 RSS，只更新目录元数据；
- 把这次的单集 ID 和上次已知的 ID 求差集，**只把新增的报出来**；
- 第一次巡检会把现有目录当基线，所以不会把几千期历史全标成「新」；
- 某个源连不上时，记录失败原因并继续检查下一个；面板底部会单独列出「暂时连不上的订阅源」。

### 有新节目之后

每条新单集后面有两个按钮：

- **查看** —— 关闭面板，在主界面打开这一期的学习页；
- **下载** —— 直接加入下载队列（走的是原有的下载流程，带哈希校验）。

单个节目右上角的「标记已读」只清掉这一档的提醒；面板上的「全部标记已读」清掉所有。已读的记录会保留在状态文件里，之后重新同步也不会再冒出来。

### 状态存在哪

`data/index/feed-state.json`。里面保存每个源的已知单集 ID、上次巡检时间、上次的错误、以及新单集列表。字节数很小，删掉它只会让下一次巡检重新建立基线。

> 巡检间隔最小 5 分钟 —— 播客不是即时通讯，没必要更密。轮询频率过高还可能被一些 CDN 限流。

## 二、AI 发现

目标：**不靠别人推荐，让系统自己找到你想听的节目，并且自己关注上。**

### 先写下兴趣

在「AI 发现」页签的文本框里写下主题，逗号或换行分隔，例如：

```
人工智能, 独立游戏开发, 摄影
```

顺手设置两项：**检索地区**（不同地区的 Apple 目录收录不同）和**每次自动关注几档**（1 – 10）。点「保存兴趣」。

想固定排除某类节目，可以复制 `data/index/interests.example.json` 为 `interests.json`，在 `exclude_keywords` 里填排除词（例如不想听新闻类就填 `news`）。这个文件不会被提交到仓库。

### 两种用法

**「让 AI 自己去找并关注」** —— 一步到底：

```
检索 → 排序 → 关注 → 同步目录 → 存封面
```

**「只推荐给我看」** —— 先看候选列表，每档带匹配分和推荐理由，勾选之后再点「关注选中的节目」。适合第一次用、还不放心放手的时候。

面板下方还有一个直接搜索框，输入节目名或主持人就能搜到并单独关注。

### 排序是怎么来的

| 情况 | 谁排序 | 说明 |
|---|---|---|
| 配置了模型密钥 | 你的模型 | 把候选的名称、作者、类型、期数、命中关键词交给模型，让它挑出真正匹配的，并给一句中文理由。 |
| 没有密钥 | 本地规则 | 透明的加权打分：节目名/作者命中主题 > 仅类型命中；排除词大幅降权；兼顾期数和更新活跃度。 |

本地规则的存在是刻意的：**没有密钥也能用**。它不如下判断，但足以把候选排到一个合理顺序。

自动关注还会设一道下限——只有当候选的分数达到最高分的 40% 以上才会被自动选上，避免为了凑够数量而关注一堆不相关的节目。

### 关注之后

被关注的节目会：

1. 写进 `data/index/shows.json`（记录名称、类型、订阅地址、来源是 AI 还是手动、以及推荐理由）；
2. 立刻同步一次 RSS 目录，形成 `data/library/<slug>/catalog.json`；
3. 保存封面到 `data/library/<slug>/cover.jpg`。

然后它会和原有节目一样出现在侧栏、筛选器和列表里，并且自动纳入订阅巡检。

### 取消关注

「设置」页签底部列出所有已关注的节目，每行有「取消关注」。

取消关注会把整个节目文件夹**移动**到 `data/archive/<slug>/` —— 不删除。下载过的音频、生成的字幕、笔记都还在，想恢复就把它移回 `data/library/`。

> 说明：节目列表是从磁盘上的目录文件夹扫出来的，所以取消关注必须移动文件夹才能真正从列表里消失。选择「移动而不是删除」是为了不让你误删已经花时间下载和转写的内容。

## 三、模型密钥（「设置」页签）

支持 DeepSeek 和任意 OpenAI 兼容接口。

**方式一：填在界面里。** 选服务商 → 确认接口地址和模型名 → 粘贴密钥 → 保存。Windows 下密钥用当前账户的 DPAPI 加密后存在 `data/index/discovery-settings.json`，换个 Windows 账户就解不开，需要重新填。

**方式二：环境变量。** 完全不写文件：

```powershell
set PODCAST_LLM_API_KEY=你的密钥
set PODCAST_LLM_BASE_URL=https://api.deepseek.com
set PODCAST_LLM_MODEL=deepseek-chat
```

环境变量的优先级更高，配了之后界面上的「本机加密文件」就不再生效。

**密钥永远不会出现在这个仓库里。** 保存后接口只返回「已配置 / 未配置」和来源，不回传密钥本身；上面两个配置文件也都在 `.gitignore` 里。

想清除已保存的密钥，点「清除已保存的密钥」。

## 常见问题

**自动检查开着，但一直没提醒？**
先点「立即检查全部」看有没有报错。如果面板底部列出了「暂时连不上的订阅源」，通常是网络或 DNS 问题；Windows 下程序会尝试用 PowerShell 7 的网络栈兜底，没装 PowerShell 7 时会直接报错。

**AI 发现搜不到东西？**
换关键词，或者换检索地区。Apple 的检索接口按地区分库，某些地区对中文关键词的收录较少，可以试英文关键词。

**自动关注了几档完全不相关的节目？**
说明你在靠本地规则排序（没配密钥）。把主题写得更具体，或者配上密钥让模型来挑，然后在「设置」里取消关注不需要的那几个。

**关注之后侧栏没变？**
关注成功时界面会刷新资料库。如果没变化，刷新一下浏览器页面。节目文件确实不在磁盘上才是出错了，可以在「设置」页签底部核对已关注列表。

**`data/index/shows.json` 和 `catalog.json` 出现了改动？**
正常。关注新节目会改 `shows.json`，同步会重写 `catalog.json`。这些是「你的」数据，提交或不提交都行；不想让 git 一直提示，可以把它们加进本地 `.git/info/exclude`。
