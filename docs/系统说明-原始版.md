## 打开使用

浏览器打开 [听间 · 本地播客资料库](http://127.0.0.1:8765/)。如果服务未启动，在本文件所在文件夹双击 [打开播客](打开播客.lnk)，会自动启动并打开浏览器。也可从项目首页的“英文播客 · 听间”进入。

界面已重做为暖白书架与单集阅读页。关注的节目包括 **Waveform、PetaPixel、Kinda Funny Gamescast、Hard Fork、The Vergecast、The CultCast、Accidental Tech Podcast、BBC 6 Minute English、All Ears English、Easy Stories in English**，共 10 档、7,754 条目录记录。每档均可在前端筛选、更新目录并按需下载。窄屏使用列表上方的节目筛选菜单。

点击播放会自动进入专注页，收起已下载列表与节目导航。左上角“返回书架”恢复列表，播放不中断；底部节目标题可以回到正在播放的单集。

下载会显示“排队中 / 下载中”，重复点击不会重复加入任务；失败后可点“重新尝试”。下载完成后自动刷新“已下载”列表，音频保存在本地资料库。播放器始终位于底部，支持前后 10 秒、倍速和 30 分钟停止。播放位置约每 5 秒保存一次，并在暂停时保存。

想复习时点击“标记这一段”，调整片段起止时间并写一句备注。保存后可跳回原声或循环播放。右侧笔记自动保存，也可手动点保存笔记。

字幕页点击“生成中英字幕”，一次完成 **本地音频 → 英文识别与时间戳 → API 中文翻译 → 本地保存**。英文生成后立即可读，中文逐批补齐。字幕上方可以切换“双语 / 英文 / 中文”，不改变原音频、英文原文或时间轴；点击任一句回听，默认跟随播放。默认“自动滚动”开启；手动滚动后暂缓约 6 秒，再自动跟随。划选时暂停滚动，松开后留出约 2.5 秒。点“自动滚动”可以关闭跟随，进入自由浏览。

“字幕操作”中可以重新识别并翻译、补齐中文、取消任务、导入文件及导出当前语言的 TXT / SRT。中文失败或网络中断保留已完成的部分，重试只补齐缺失的中文，避免重新识别英文。导入英文 TXT、SRT、VTT 后也会自动加入翻译队列。导出双语或中文需等整期中文完成。自动转写与翻译都可能有错词，尤其游戏、人名、双关和重叠讲话，重要表达结合原声确认。

模型位于 `99_系统文件/依赖/播客模型/whisper-large-v3-turbo`，独立环境位于 `99_系统文件/依赖/podcast-asr`。转写无需 API、不上传音频；完成后进程退出并释放其显存。带逐词时间戳的 JSON、TXT、SRT 保存到每期音频所在目录的 `transcripts/` 子目录，同时写入学习数据库。稿件标记为“本地自动转写”，不是官方稿件。

全部记录写入本机 `99_系统文件/索引/播客学习/ui.sqlite3`，音频保留在资料库原位置。侧栏“导出学习记录”可以导出笔记、播放位置、标记和文字稿的 JSON；音频需要单独备份。关闭标签页后服务仍运行，重启电脑后再双击快捷方式即可。当前只允许这台电脑访问，不支持手机跨设备访问。

## 本地转写实测

2026-09-06，在本机 RTX 5070 12GB 上，使用 faster-whisper 1.2.1、CTranslate2 4.8.2、Turbo、int8_float16、batch_size=4，包含词级时间戳和静音过滤：

| 样本 | 音频时长 | 从进程内开始到生成结果 | 其中识别阶段 |
|---|---:|---:|---:|
| Waveform 前 3 分钟 | 180 秒 | 21.62 秒 | 10.17 秒 |
| Waveform 完整单集 | 6,331.61 秒，约 105.5 分钟 | 68.81 秒 | 59.46 秒 |

完整转写生成 2,198 条短句、20,660 个识别词。句子拆分只使用识别结果和词级时间戳，已检查拆分前后词序列完全一致，时间戳均在音频范围内且开始时间不倒序。速度是这两次实际执行结果，不保证其他节目相同；不是准确率测评。单集实际长度与 RSS 声明时长可能不同，字幕绑定实际音频 SHA-256。

已生成 [Waveform 英文 TXT](资料库/waveform/episodes/405018e97308a70119d9/transcripts/e1635433c0f6420096317703e40a43dd.txt) 和 [SRT 字幕](资料库/waveform/episodes/405018e97308a70119d9/transcripts/e1635433c0f6420096317703e40a43dd.srt)，也可直接在前端查看和下载。

模型采用 [faster-whisper 上游的 Turbo 映射](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/utils.py)，固定版本 `0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf`。模型主体 1,617,884,929 字节，已按 Hugging Face 来源元数据核验 SHA-256，其他 4 个配置/词表文件核验 Git blob 哈希；下载回执保存在模型目录。Windows 修复下载工具为 `99_系统文件/工具/download_podcast_model.ps1`，环境版本清单为 `99_系统文件/依赖/podcast-asr-requirements.txt`。

Waveform 的普通下载曾遇到 TLS EOF；通过官方媒体地址发起 `Range: bytes=0-` 请求，收到覆盖完整文件的 206 响应后成功归档。保存的 HTTP 回执明确为 `bytes 0-152013380/152013381`。这里是一次完整响应，不是将多个可能含不同广告的下载版本拼在一起。工具已补充完整范围校验；网络问题仍可能随环境变化。

## 边听边划词

字幕上方“划选即收藏 · 开”默认开启。用鼠标在同一句英文或中文里拖过一个词或短语，松开即保存，音频继续播放，不触发跳播。英文会自动补齐到单词边界，避免扫得太快只记下半个单词；中文按实际选中文字保存。一次支持最多 500 字符，跨句、跨语言选区会提示重新选择。关闭此开关后可以普通选中、复制文字。

收藏会立即保存选中文字、中英原句快照、节目、字幕版本、音频版本、起止时间和收藏日期，再由已有的 DeepSeek API 补齐对应词义（默认 Flash，结构或对应关系异常尝试 Pro）。这不是只保存整段翻译：例如 low-key 会保存“low-key／低调”，划选中文“低调”也会对应到英文原句中的 low-key。自动释义应结合原句核对。

“片段与笔记”里可以看本集生词；返回书架进入“生词本”可搜索全部收藏、查看双语原句、回听原片段和导出 JSON。选中的文字会在原字幕中留下浅色标记。同一版字幕、同一句、同一语言和同一选词重复划选不会重复建立记录。误划可立即撤销；移除后可在生词本的“查看已移除的收藏”恢复。

数据自动写入本机 `99_系统文件/索引/播客学习/ui.sqlite3` 的 `vocabulary` 表，重启服务或电脑后保留，原句快照不会随重新识别字幕而被覆盖。独立“导出生词本”和“导出学习记录”都包含这些记录及移除标记。网络失败只影响补充词义，已经保存的词和原句仍在；可点“补齐词义”重试。服务重启会继续处理未完成的词义任务。若页面提示“保存失败”，则需重试并等到“已收藏”确认。

## 翻译模型、费用与保存

默认 **DeepSeek V4 Flash**，先对异常结果重试；仍漏句、行号不匹配或整批未翻译时尝试 **V4 Pro**，必要时继续缩小批次。自动检查保证行数与对应关系，不是对每句语义的准确性认证。设置中的 Pro 可用于之后的新翻译任务；已完整保存的中文不会因修改默认模型自动重写。

英文识别继续使用 RTX 5070；只有英文字幕及相邻句、节目标题发送给 DeepSeek，音频留在本机。结果保存成逐句对应的 JSON、双语 TXT / SRT，并写入 SQLite。后续回听、语言切换和导出均不再调用 API。

“翻译设置”可以保存或替换官方 API 密钥。密钥由当前 Windows 账户的 DPAPI 加密，仅本机后端解密使用；前端与学习记录导出不返回密钥。迁移到另一个 Windows 账户后需要重新填写。

按 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（2026-09-06）粗估，Flash 翻译这一期 105.5 分钟 Waveform 约人民币 0.5–1 元，包含分段与格式开销；实际用量随输出、时段、重试与 Pro 回退变化，本次调试也产生了重试费用，不能把预估当账单。Pro 同类 token 单价约为 Flash 的 3 倍，以控制台账单为准。接口参数依据 [官方 API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

本地翻译可另行部署量化翻译模型，例如 [HY-MT1.5-7B](https://huggingface.co/tencent/HY-MT1.5-7B)；其量化权重可以落在 12GB 显存范围内，但速度、上下文占用及播客术语效果需要本机实测。没有做与 DeepSeek V4 的同集盲测，不能宣称 API 必然胜过这张显卡可运行的所有模型。目前选择 API 是为了省去第二套本地模型维护，并利用已验证可用、按次费用较低的翻译流程。

## 工具如何运行

在 PowerShell 中进入项目根目录后运行。工具使用应用现有 Python；Windows 网络兼容层使用已安装的 PowerShell 7，无第三方 Python 包依赖。可复制下面两行设置路径：

```powershell
$podcastPython = '<你的 Python 解释器路径>'
$podcastTool = '<仓库根目录>/app/podcast_archive.py'
```

更新 Waveform 目录（不会自动下载全部音频）：

```powershell
& $podcastPython $podcastTool sync waveform 'https://feeds.megaphone.fm/STU4418364045'
```

下载当前目录最新一期（已保存且哈希一致就跳过）：

```powershell
& $podcastPython $podcastTool download waveform latest --direct-megaphone
```

`--direct-megaphone` 仅使用 RSS 媒体 URL 已明确包含的 Megaphone 目标地址，保留原始 URL 作为来源，不猜测私有地址。其他节目正常使用 `download 节目标识 单集ID`。暂存失败后重新完整下载，不跨请求盲目断点拼接。

更新摄影节目目录并下载最新一期：

```powershell
& $podcastPython $podcastTool sync petapixel 'https://anchor.fm/s/e3085708/podcast/rss'
& $podcastPython $podcastTool download petapixel latest
```

校验已归档媒体：

```powershell
& $podcastPython $podcastTool verify waveform
& $podcastPython $podcastTool verify petapixel
```

手动导入已有 MP3/M4A（先同步节目目录，单集 ID 见 catalog.json）：

```powershell
& $podcastPython $podcastTool import-audio waveform '单集ID' 'C:/你的音频.mp3'
```

导入的音频会明确标为用户文件，不凭文件名假定来自官方。重复导入不会覆盖已有资产。

## 原型限制

界面中的同步、下载、转写与翻译进入同一个串行队列（单次翻译最多并发 3 批），避免互相覆盖；请不要同时在命令行运行相同节目的任务。任务队列暂存在服务进程中，电脑重启后未完成的任务需重新点击；已经完成的文字稿和笔记仍保留。转写默认英语，需 NVIDIA GPU；显存不足时关闭占用显卡的软件后重试。时间戳来自自动识别，不保证逐词精确，也不自动区分说话人。发现 RSS transcript 链接只记录它，不自动下载。Windows 网络后备会先暂存响应，大小上限在暂存完成后校验，不能把这个参数当作网络流量硬限额。

没有默认下载全部历史。最新保存的单集数量在前端“已下载”中查看；稿件来源状态、每期文件哈希和实际执行结果可在资料库的 JSON 中核对。
